# Penjelasan
Dokumen ini menjelaskan bagian `frontend` pada aplikasi ini.

# Tampilan
Layar frontend menampilkan tentang status dari backend dan form upload dokumen mahasiswa.

# Cara Penggunaan
1. Tekan tombol "Telusuri..." atau semacamnya (tergantung bahasa pada browser) untuk memilih file.
2. Pilih file dari komputer.
3. Jika file sudah terpilih, maka tekan tombol "Upload File".
4. Upload berhasil.
